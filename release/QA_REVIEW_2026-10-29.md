# Gameplay and UI review — 2026-10-29

Android review using the minified QA/performance builds, not Metro screenshots. Normal display: 1080×2340 at density 440, font scale 1.0 (about 393×851 dp). Stress display: 720×1280 at density 320, font scale 1.5 (360×640 dp). The emulator display overrides were restored afterward.

## Corrections

- Keep the gameplay sign below the system status area on short phones; preserve board clearance above the action row and full board size on tall phones.
- Keep the painted Levels heading below Back/coins, with the scrolling grid confined below it. Shrink its coin pill to avoid crowding the artwork.
- Keep Shop's live caption legible inside its painted band. Utility tabs have 44-point minimum height and can wrap.
- Measure purchase headers before placing their cream backing. Stack actions at enlarged text/compact widths and keep price labels within buttons.
- Keep deletion Cancel/Delete visible while the warning copy scrolls. Stack full-width actions at enlarged text/compact widths and omit the decorative trash symbol there to retain reading space.
- Clip Settings, Daily, Awards and Coins & Ad-Free scrolling below the system status area; retain normal initial spacing.
- Fit win statistics into the painted stats area. Body text continues to respect system font scaling; artwork-bound labels use bounded scaling.
- Pop the completed game when returning Home, preventing Back from reopening a consumed win screen.

No new assets, dependencies, economy rules, level data or gameplay-engine rules were added. Existing WebP source quality was retained.

## Automated checks and builds

- TypeScript and ESLint pass.
- Jest: **764 tests / 33 suites pass**, including 11 viewport-layout regressions. Used `npm test -- --runInBand --watchman=false` because the sandbox blocks Watchman's socket setup.
- All **100 levels** pass geometry, exact-par and solvability validation.
- Asset audit passes: **47 imported WebPs, 2.28 MiB encoded**; source dimensions, budgets, native font/audio copies and font licence checked. Aggregate decoded size is 51.99 MiB; this is not measured live memory. Vehicle-cache upper bound: 10.87 MiB RGBA.
- Node hint benchmark: worst sampled **1.35 ms**, level 58, within the 6 ms budget. This is not a phone measurement.
- Ads configuration validates in **test mode**. Production activation remains the publisher's deferred task.
- Android QA APK, performance APK and signed release AAB builds pass. `jarsigner -verify` confirms the final bundle signature (normal self-signed upload certificate). Final app-process log check showed no AndroidRuntime/ReactNativeJS errors.

The normal performance APK is installed on the emulator. Output: `android/app/build/outputs/apk/performance/app-performance.apk`. Release bundle: `android/app/build/outputs/bundle/release/app-release.aab`.
